# EV-RAS

Emergency Vehicle Route Alert System.

EV-RAS is a real-time emergency vehicle awareness platform
that uses road-network analysis and predictive intelligence
to identify drivers who may encounter approaching emergency
vehicles and deliver targeted warnings.

## Technology

- NestJS and TypeScript
- pnpm workspace
- Geospatial route analysis
- Real-time WebSocket communication
- Machine learning
- React and MapLibre

## Development

The backend application lives in `apps/api`.

Install dependencies:

    pnpm install

Start the API:

    pnpm dev:api

Run tests:

    pnpm test:api
